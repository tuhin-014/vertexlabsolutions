What tax returns does an executor have to file?

Part of Settle's executor guides · 51 jurisdictions · state content checked 2026-09 · page generated 2026-09-27

At minimum a final personal income tax return for the year of death, and an estate income tax return if the estate earns income while it is open. Whether a state estate or inheritance tax return is also due depends entirely on the state.

What this involves

A final personal return (and possibly an estate income return) is due.

How: A CPA experienced with estates is usually worth it -- hand them Settle's reports.

Applies in 41 of the 51 jurisdictions Settle covers.
